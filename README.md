# Курс по Go — десктопное приложение для Windows

Учебное приложение «Курс по Go» для Windows 10/11: теория короткими уроками, практика с
автопроверкой, геймификация в стиле Duolingo (стрики, XP, лиги, достижения), нативные
Windows-уведомления и Telegram-бот. Программа курса построена по roadmap.sh/golang и
покрывает путь от первого `hello world` до финальных проектов уровня junior+/middle.

Дизайн-система: тёмная тема Apple HIG (минимализм, «воздух», SF-подобные иконки Lucide,
без эмодзи и градиентов), нативная рамка Windows с поддержкой Snap Layouts.
Минимальный размер окна — 1024×700.

---

## Технологический стек

| Слой | Технология | Почему |
|---|---|---|
| Десктоп | Electron 38 + electron-vite | Нативные Windows-рамка, toast-уведомления и Планировщик задач из коробки; одна кодовая база с вебом |
| UI | React 19 + TypeScript (strict) | Компонентная модель, типобезопасность IPC-контрактов |
| Состояние | Свой reducer (immutable state) | Простая доменная логика без внешних зависимостей |
| Контент курса | JSON-сиды + валидатор | 75 уроков и 304 задания проверяются на CI |
| Автопроверка кода | Встроенный Go toolchain (`go vet`/`go test`) | Задания `write_code` проверяются локально, без сети |
| Бот | Node.js без зависимостей (long-polling Bot API) | Запускается как фоновый процесс рядом с приложением |
| Сборка | electron-builder (NSIS + portable) | Установщик и переносная версия для Windows |

Облачный бэкенд из ТЗ (PostgreSQL/Redis) не требуется: приложение полностью офлайновое,
прогресс хранится локально, бот работает на той же машине и читает те же данные.

## Быстрый старт

Требования: Node.js 20+, для заданий `write_code` — установленный Go 1.22+.

```bash
npm install
npm run dev          # разработка (electron-vite)
npm test             # unit-тесты доменной логики и контента
npm run validate:content   # валидация сид-контента
npm run build        # typecheck + сборка в out/
npm run dist         # установщик NSIS + portable в release/
```

## Telegram-бот

```bash
copy .env.example .env    # укажите TELEGRAM_BOT_TOKEN от @BotFather
npm run bot
```

Бот выполняет:

* привязку аккаунта по deep-link `https://t.me/<bot>?start=<token>` (кнопка в «Профиле»);
* локальный API `GET /link/<token>` → `{ "chatId": ... }` для проверки статуса привязки;
* команды `/start`, `/streak`, `/progress`, `/unlink`;
* напоминания: «Стрик в опасности» (за 6 часов до полуночи), «Финальный дедлайн»
  (за 30 минут), утреннее сообщение о сгоревшем стрике;
* анти-спам: не более 4 сообщений в день, дедупликация по (chat_id, дата, тип),
  кнопка «Отложить на 1 час»; при блокировке бота отправка отключается.

Формат сообщений — Markdown, без эмодзи. Если приложение закрыто, напоминания приходят
через задачу «Go Course Reminder» в Планировщике Windows (создаётся из «Профиля») —
приложение запускается скрыто с флагом `--remind`, показывает toast и завершается.

## Контент курса

9 блоков, 75 уроков, 304 задания семи типов: `single_choice`, `multiple_choice`,
`code_output`, `fill_code`, `find_bug`, `order_lines`, `write_code` (автопроверка
скрытыми тестами). Блоки 0–1 содержат по 6–8 заданий на урок, проектные модули
блока 7 — чек-листы шагов с фиксацией прогресса.

Сид-контент лежит в `src/shared/content/blocks/` и проверяется на:

* структуру (уникальность id, полноту полей, перестановки `order_lines`,
  единственный пропуск `___` в `fill_code`, диапазон `bugLine`);
* отсутствие эмодзи (требование дизайн-системы);
* непустые объяснения каждого задания.

## Тесты

`npm test` — vitest: даты в таймзонах, стрики и заморозки, XP/уровни/комбо, лиги
(детерминированные таблицы, повышение/понижение), планировщик уведомлений
(тихие часы, горящий стрик), reducer прогресса и полная валидация контента.

## Безопасность

* Код пользователя из `write_code` выполняется в песочнице временного модуля:
  `go vet` + `go test` с таймаутом 5 секунд, без сети; показываются только имена
  упавших тестов.
* Секреты (токен бота) — только через переменные окружения, `.env` в `.gitignore`.
* Данные пользователя хранятся локально, атомарная запись с резервной копией.
